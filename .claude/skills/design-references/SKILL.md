# Design references

Before designing a page or section, pick the 2 to 3 sources below that match the task, look at what they show, and name the references you drew from. Borrow layout, rhythm, and motion ideas; never copy a specific site's identity, copy, or branding. The project's own brand guidelines always win.

## By task

| Task | Look at |
|---|---|
| Whole landing page, overall direction | land-book.com, supahero.io, godly.website, theinternetdesigns.com |
| Full site references | supply.madebyoversight.com (192+ sites) |
| A single section (hero, features, pricing, FAQ) | supply.madebyoversight.com/sections (51 sections) |
| Call to action blocks and buttons | cta.gallery |
| Footers | footer.design |
| Motion and scroll animation | 60fps.design, scrolltide.co (600+ animation prompts) |
| AI video for heroes and promos | supply.madebyoversight.com/videos (AI video kits) |
| Prompts for AI design tools | onepromptdesign.com, scrolltide.co |
| General creative inspiration | inspora.design, on.design (design community) |
| Design resources (fonts, tools, assets) | devault.design |

## Notes

- Most of these are image or video galleries. Fetching them as text often returns little; when that happens, say so and ask the user to share screenshots or links to specific examples they like.
- For faux product UI in heroes and feature cards, use the `stageshow` skill. For real React app UI, use `fluid-functionalism`.
